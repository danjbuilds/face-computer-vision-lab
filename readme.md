# Face Computer Vision Lab

A personal learning repository documenting my progression from OpenCV fundamentals to MediaPipe facial landmark analysis and basic liveness detection.

## Learning Order

### OpenCV Fundamentals

- 01_live_video.py
  - Camera initialization
  - Reading frames
  - Displaying live video
  - Mirroring frames

- 02_color_spaces_grayscale.py
  - BGR
  - RGB
  - Grayscale

- 03_resizing_images.py
  - Image resizing
  - Aspect ratio

- 04_cropping_roi.py
  - Region of Interest (ROI)
  - Image slicing

- 05_image_blurring.py
  - Gaussian Blur
  - Noise reduction

- 06_edge_detection.py
  - Canny Edge Detection

- 07_contours.py
  - Finding and drawing contours

---

### YuNet Face Detection

- 08_yn_face_detection.py
  - Face detection
  - Bounding boxes
  - Confidence scores

- 09_yn_face_landmarks.py
  - Facial landmarks returned by YuNet

- 10_yn_head_pose.py
  - Head pose estimation

---

### MediaPipe

- 11_mediapipe_face_landmarker.py
  - Face Landmarker Tasks API
  - 478 landmarks

- 12_face_mesh_connections.py
  - Mesh topology
  - Facial connections

- 13_mediapipe_face_mesh.py
  - Landmark visualization
  - Coordinate conversion

---

### Facial Geometry

- 14_blink_detection_lab.py
  - Eye Aspect Ratio (EAR)
  - Blink detection
  - Long eye closure detection
  - Time-based state tracking

## Notes

Each file is an independent experiment focused on learning a single concept. Files are numbered in the order they were studied.
